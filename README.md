# ATSify - TypeScript Node + Express + Mongo scaffold

This project is a minimal scaffold for a TypeScript Node.js application using Express and MongoDB.

Quick commands (PowerShell):

```powershell
# install dependencies (already done by the scaffolder)
npm install

# development (auto-restart)
npm run dev

# build
npm run build

# start (production)
npm start
```

See `.env.example` for environment variables.
